# Бот для Telegram-канала

Публикует посты по расписанию из `config.json`: раз в два часа с 9 до 22 по Москве, каждый раз в случайную минуту окна (`jitter_minutes`), например 13:18, потом 15:31. Время выбирается заранее и одинаково для всех запусков, поэтому пост не выйдет дважды. Работает на GitHub Actions, API Claude для публикации не нужен.

Что выходит в каждый слот:
1. В слотах `meme_slots` выходит мем: видео или картинка из r/Brawlstars (нужны ключи Reddit API), а без ключей Shorts официального канала Brawl Stars со встроенным плеером.
2. Иначе выходит свежая новость: новое видео с YouTube-канала Brawl Stars или новая статья из блога Supercell с официальной картинкой. Таких постов не больше `max_news_per_day` в день.
3. Иначе выходит следующий пост из `queue.json`.

Свежие материалы бот собирает сам перед каждым слотом и складывает в `inbox.json`, а уже виденные запоминает в `seen.json`. Эти файлы руками не правь. При первом запуске бот только запоминает старые видео и статьи, чтобы не завалить ими канал.

## Управление из Telegram

Напиши своему боту в личку /start (бот отвечает только админам канала). Внизу появятся кнопки:
- **📋 Очередь**: сколько постов ждут, когда следующий, и у каждого поста кнопки 👁 посмотреть, 🚀 опубликовать сейчас, ✏️ заменить текст или медиа, 🗑 удалить.
- **⏰ Следующий пост**: время ближайшей публикации.
- **Новый пост**: пришли боту текст, фото, видео или GIF с подписью (форматирование сохранится) и выбери: опубликовать сейчас, следующим или в конец очереди.

**Модерация чата.** Добавь бота администратором в чат обсуждений канала с правом удалять сообщения и банить. Бот присылает владельцу канала сообщения о нарушениях (реклама и ссылки, «бесплатные гемы» и мошенничество, продажа аккаунтов, читы, 18+, политика, оскорбления и травля, телефоны, флуд) с кнопками «Удалить», «Удалить и забанить», «Оставить». Мат не считается нарушением. Правила лежат в `RULES` в `admin.py`.

Админ-бот работает внутри цепочки `post.yml`, пока она ждёт следующего поста, поэтому отдельный сервер не нужен. Между звеньями цепочки бывают паузы на несколько секунд, а за 4 минуты до поста бот занят публикацией: сообщения в это время он прочитает чуть позже.

## Источники
- Видео: новые ролики на русском с каналов ютуберов из `video_channels` в `config.json`, со ссылкой на канал автора. Shorts и ролики не на русском пропускаются.
- Мемы: видео с Reddit через официальный API (нужны ключи), без ключей русские Shorts с каналов из `meme_channels`.
- Обложки: кадры из мультфильмов официального канала и скриншоты из геймплейных роликов ютуберов (подпись «Кадр: канал»). Кадры с живыми людьми отсеиваются.
- Расписание: посты через случайные 90-110 минут (`interval_minutes`) с 9 до 22 по Москве (`day_start`, `day_end`).

## Настройка
1. Settings → Secrets and variables → Actions → Secrets: `TELEGRAM_BOT_TOKEN` с токеном бота.
2. Там же на вкладке Variables: `TELEGRAM_CHANNEL`, например `@All_About_Brawl`.
3. Необязательно, если Reddit отвечает 403: создай приложение типа «script» на https://www.reddit.com/prefs/apps и добавь секреты `REDDIT_CLIENT_ID` и `REDDIT_CLIENT_SECRET`.

4. Ключ Gemini: открой https://aistudio.google.com/apikey, нажми Create API key и добавь его в Secrets как `GEMINI_API_KEY`. Ключ бесплатный.

### Как работает точное время
Внешние сервисы не нужны. `post.yml` работает цепочкой: каждый запуск спит до момента за 4 минуты до ближайшего слота, собирает свежие материалы, ждёт назначенную минуту, публикует пост и сам запускает следующее звено. Ночью звенья просыпаются раз в 5,5 часа и спят дальше.

Запуск цепочки: Actions → post → Run workflow, без галочек. Если цепочка оборвалась (например, из-за сбоя GitHub), её перезапускает `watchdog.yml`. Если GitHub не запускает его по расписанию, снова нажми Run workflow в post.

Run workflow с галочкой «Опубликовать следующий пост прямо сейчас» сразу отправляет пост из очереди. Поле «Пробный пост» сразу публикует самый свежий мем, новость или видео из источника. Эти запуски цепочку не трогают.

### Кто пишет посты
`writer.py` (workflow `write.yml`) просит Gemini найти свежие новости в Google и написать посты по правилам канала. Скрипт проверяет каждый пост, рисует обложку, для статей Supercell берёт официальную картинку, а посты с запрещёнными темами или с источником, который не подтвердил поиск, выбрасывает. Пополнение запускается каждую ночь, а также из цепочки, когда в очереди остаётся меньше 6 постов.

## Формат постов в queue.json
- Текст: `{"type": "text", "text": "<b>Заголовок</b>\nТекст"}`
- Фото из репозитория: `{"type": "photo", "image": "images/post.png", "text": "подпись", "source": "https://...", "source_name": "Supercell"}`
- Фото по ссылке: `{"type": "photo", "image": "https://...", "text": "подпись"}`
- Видео до 50 МБ: `{"type": "video", "video": "videos/post.mp4", "text": "подпись"}`
- Видео с YouTube в посте: `{"type": "text", "text": "...", "video_url": "https://www.youtube.com/watch?v=...", "source": "тот же адрес", "source_name": "YouTube: канал"}`
- Опрос: `{"type": "poll", "question": "...", "options": ["...", "..."]}`
- Опрос с картинкой: добавь `image` и `text`. Картинка выйдет отдельным сообщением перед опросом.

Символы `&` и `<` в тексте пиши как `&amp;` и `&lt;`. Строку источника бот добавляет сам. Уведомление о неофициальном материале нужно держать в описании канала.
- Официальная картинка по ссылке: `{"type": "photo", "image": "https://...", "fallback_image": "images/обложка.png", ...}`. Если Telegram не заберёт ссылку сам, бот скачает картинку и загрузит её файлом.

Новые посты добавляй в конец файла. `state.json` хранит номер следующего поста и последний отработанный слот, его трогать не нужно.

## Проверка
```bash
python3 bot.py --check
python3 -m pytest tests -q
```

Правила для автора постов лежат в `CLAUDE.md`. Обложки рисует `tools/make_image.py`, ему нужен пакет Pillow. Таблицы рисует `tools/make_table.py`. Анимированные ролики делает `tools/make_video.py`, ему нужны Pillow и ffmpeg.
